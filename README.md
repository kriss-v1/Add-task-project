# Add-task-project

##🔹 Features
Add tasks — Type a task and click Add.
Complete tasks — Click a checkbox to mark a task as completed.
Delete tasks — Remove tasks you no longer need.
Filter tasks — Show:
All
Active
Completed
LocalStorage — Tasks remain saved even after refreshing the page.
Dark/Light mode — Toggle between themes.
Task counter — Display something like 3 tasks remaining.
